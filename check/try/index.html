Start from a worked example

Captive services study, mechanics clean

A ₹120 crore captive software services engagement benchmarked on TNMM / OP-OC against ten comparables. The range was built by the position method and the margin sits inside it, so the study concludes no adjustment. This is what a mechanically sound file looks like — which is not the same as a file whose comparables are right.

Load the Excel-percentile trap

The same file, with the range taken from Excel's PERCENTILE.INC (4.24% – 7.22%) instead of the position method of Rule 10CA(7)/(9) (4.00% – 7.40%). The tested party's 4.10% falls inside the statutory range and outside the interpolated one, so the study concluded a ₹2.16 crore adjustment to the median that Rule 10CA(5) does not support. Watch A1 name the interpolation and A5 catch the adjustment.

Fewer than six comparables (tolerance band)

Four comparables only, so Rule 10CA(4) allows no range at all: the arm's length price is the arithmetic mean and the transaction is tested against the band notified under the proviso to s.92C(2) — 3% OF THE TRANSACTION PRICE, not three percentage points of the margin. That distinction is why this check asks for rupee amounts and refuses to answer without them.
